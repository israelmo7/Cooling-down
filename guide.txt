Cooling down 1.0


BUILD TIME (Mac)

  Server
    cd server-ssh
    docker build -t cooling-down-server:1.0.0 .
    sh apply.sh
    → Token printed. Admin: http://localhost:8080/admin

  Client (Android emulator)
    cd tablets
    flutter run -d <emulator-id>
    Settings:
      כתובת המחשב  http://10.0.2.2:8080
      אסימון גישה   <Token>
      סנכרון עכשיו


PRODUCTION TIME (shop)

  Server (pack on Mac, run on Windows)
    sh server-ssh/pack-windows.sh
    Copy server-ssh/dist/cooling-down to the Windows PC.
    Edit shop.json. Docker Desktop on. Then:
      powershell -ExecutionPolicy Bypass -File .\start.ps1
    → Token printed. Admin: http://localhost:8080/admin
    Give the PC a fixed LAN IP.

  Client (real Android tablets)
    cd tablets && flutter build apk --release
    Install tablets/build/app/outputs/flutter-apk/app-release.apk
    Settings on each tablet:
      שם הסביבה    <one name per fridge — set before first sync>
      כתובת המחשב  http://<shop-pc-lan-ip>:8080
      אסימון גישה   <same Token>
      סנכרון עכשיו
    Same shop Wi‑Fi as the PC.

  Field notes
    Sync pending rows before changing PC address or token on a tablet.
    After TZ change on Windows, recreate the container (start.ps1 again).
    Keep the shop PC running across report time; restart catches up ~7 days.
    Never copy SYNC_TOKEN between two shops.
